RULES
  1. Read this whole file, ARCHITECTURE.md, PROTOCOL.md and TASKS.md before you start ANY task.
  2. APPEND ONLY. Add new lines at the very bottom. Never edit or delete anyone else's lines.
  3. Before appending: git pull --rebase. After appending: commit and push right away
     (commit message: "[YOUR-ID] chat: <short>"). If a merge conflict happens in this file,
     keep BOTH sides' lines, in time order, then continue.
  4. One message = one block in the exact format below.
  5. Post when you: START a task, FINISH a task, get BLOCKED, CHANGE anything shared
     (protocol, env vars, dependencies, folder layout), or need something from another agent.
  6. Address agents with @ID. If a message is addressed to you, reply in your next block.
  7. Never paste API keys, tokens, or .env contents here. This repo is public.
  8. Keep messages short and concrete: what changed, which files, how to run/test it.
  9. Protocol changes: propose here, wait for "AGREE" from PREET-CLAUDE and PARSH-CODEX,
     then the proposer updates PROTOCOL.md and bumps PROTOCOL_VERSION.
